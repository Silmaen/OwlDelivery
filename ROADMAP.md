# Roadmap

What is planned, by target version. What has shipped lives in [CHANGELOG.md](CHANGELOG.md).

## 0.5.0

- Home page: Owl Engine in one screen, a Discover link, the latest release and the 3 latest news ([spec](doc/specs/site-pages.md)).
- Presentation page: screenshots, features, downloads, sample games, roadmap, how it is built ([spec](doc/specs/site-pages.md)).
- Pages admin tab to edit every text, image and list of both pages without a redeploy.
- API actions `push_screenshot` and `push_release` so the engine CI feeds the presentation page.
- OAuth authentication support.
- Email notifications for new releases and comments, with tunable preferences.
